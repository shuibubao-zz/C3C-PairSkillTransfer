# 教学记录证据来源说明

## C3C 的硬性要求

CHALLENGE.md Level 2 要求“至少 2 次有记录的教学会话（截图 / 录屏 / 聊天记录）”。
本目录提供的 2 份文件是**依据 P27 工作材料复盘的知识迁移事件记录**，不满足该硬性要求。

## 为什么不能直接写“教学会话”

| 材料里有的 | 材料里没有的 |
|---|---|
| 两人各自做了什么、修正了什么 | 谁在什么时候向谁讲解了什么 |
| 靖雪晴逐条核对库表字段、改正终端绑定与密码引用 | 带时间戳的聊天/录屏/截图 |
| 靖雪晴补前置登录步骤、补异常场景数据（进行中） | 教学会话的参与人、地点、形式 |
| 卢怡然执行接口实测、修正冒烟脚本参数 | 搭档本人对教学事件的确认 |

在缺少原始记录的情况下把“两人都做了相关核对”写成“完成 2 次教学会话”，属于编造证据，
因此本包明确标注为证据等级 B，并在交付清单中列为未满足项。

## 补齐清单（交给搭档即可操作）

1. 从微信/群聊导出 2 段相关对话截图，需包含日期、参与人、具体内容：
   - 建议 1：终端号/密码口径核对的对话；
   - 建议 2：异常场景或用例前置登录步骤的对话。
2. 或录制 2 段各 10–15 分钟的复讲视频（一方讲、一方提问），保留原始文件与本目录索引。
3. 两人在 `技能画像_靖雪晴.md`、`学习笔记_靖雪晴.md` 末尾签字确认（姓名 + 日期）。
4. 提供专业证明或本人填写专业字段，用于判定“至少一人非计算机专业”。

补齐后请把文件放入本目录，并更新 `README.md` 与 `evidence/acceptance_matrix.json` 中对应状态。
